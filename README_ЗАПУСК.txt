FinPulse запускается через локальный сервер.

Не открывайте index.html двойным кликом: часть JavaScript-модулей и PWA-функций может не работать в режиме file://.

Как запустить:

1. Откройте папку Финансы_кодекс.
2. Дважды нажмите Запустить_FinPulse.bat.
3. Откроется адрес http://127.0.0.1:5173
4. Не закрывайте черное окно сервера, пока пользуетесь приложением.

Если браузер не открылся сам, откройте вручную:

http://127.0.0.1:5173

PIN демо-приложения, если уже создавали при первом запуске: тот, который вводили сами.
Если нужно сбросить, на экране PIN есть кнопка сброса.
